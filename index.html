3. Terminal Compilation Cheat-Sheet

Copy-pasteable build commands for POSIX / Linux terminals (Ubuntu, Debian, macOS, or WSL):

Terminal • Compilation Pipelines 
# --- 1. LEX & YACC Calculator Pipeline ---
yacc -d calc.y                  # Generates y.tab.c and y.tab.h
lex calc.l                      # Generates lex.yy.c
gcc lex.yy.c y.tab.c -w -o calc # Links tokenizer + grammar
./calc                          # Run interactive calculator

# --- 2. Constant Propagation & Folding ---
gcc constant_propagation.c -o const_prop && ./const_prop

# --- 3. FIRST Set of Grammar ---
gcc first_of_grammar.c -o first_set && ./first_set

# --- 4. Intermediate Code Generator (Three-Address Code) ---
gcc intermediate_code.c -o icg && ./icg

# --- 5. Shift-Reduce Parser ---
gcc shift_reduce_parser.c -o srp && ./srp

# --- 6. Lexical Analyzer in C ---
gcc lexical_analyser_c.c -o lex_c && ./lex_c
