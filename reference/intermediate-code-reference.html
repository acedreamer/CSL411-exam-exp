Three-Address Code (TAC) Cheat Sheet

Instruction formats, decomposition recipes, quadruple tables, and relational jump templates.

1. What is Three-Address Code?

Definition: Three-Address Code (TAC) is an intermediate representation where each instruction has at most one operator on the right-hand side and at most three operand memory addresses (typically two sources and one destination):

x = y op z     /* Binary operation: destination x, source operands y and z */
x = op y       /* Unary operation: destination x, single source operand y  */
x = y          /* Copy instruction: value of y loaded into x               */
goto L         /* Unconditional branch to instruction label L             */
if x relop y goto L  /* Conditional branch based on boolean predicate      */

Complex AST expressions like x = a + b * c - d cannot execute atomically on hardware; they must be linearized into a chronological sequence of elementary three-address instructions using compiler-generated temporary variables (temp, temp1, etc.).

2. The Three TAC Generation Recipes

Category Input Pattern Algorithmic Recipe Generated TAC Output
1. Assignment Statement a = b + c
or a = b		 1. Search for '=' pivot.
2. Split string into lhs and rhs.
3. If rhs has an operator (+,-,*,/), emit binary TAC.
4. Otherwise, emit simple copy TAC. 		temp = b + c
a = temp
(Simple):
temp = b
a = temp
2. Arithmetic Expression a * b - c
or a + b * c		 1. Scan left-to-right for high-precedence operators (*, /).
2. If found, evaluate temp = left op right first.
3. Fold remaining operand into temp1 = temp op remainder.
4. If only +,-, evaluate strictly left-to-right. 		For a*b-c:
temp = a * b
temp1 = temp - c

For a+b*c:
temp = b * c
temp1 = a + temp
3. Relational Expression a <= b
or x > y		 1. Emit conditional jump to true branch (addr + 3).
2. Emit fall-through assignment for false (T = 0).
3. Emit unconditional skip jump (goto addr + 4).
4. Emit true assignment target (T = 1).
5. Advance base address: addr += 4. 		100: if a <= b goto 103
101: T = 0
102: goto 104
103: T = 1
(Next addr: 104)

3. IR Data Structures: Quadruples vs. Triples vs. Indirect Triples

In production compilers, TAC is stored in structured tables rather than raw text. Here is how the three representations store t1 = b * c; a = a + t1:

Representation Structure Fields Sample Record Entry Key Trade-Off for Viva
Quadruples (op, arg1, arg2, result) (0) [*, b, c, t1]
(1) [+, a, t1, a] 		Explicit temporary names. Reordering instructions during code optimization is trivial because arguments refer to variable names, not instruction positions. Consumes 4 memory slots per record.
Triples (op, arg1, arg2) (0) [*, b, c]
(1) [+, a, (0)] 		No explicit temporary names; results are referenced by table indices like (0). Saves memory, but moving or deleting an instruction forces rewriting all pointer references throughout the entire table.
Indirect Triples Pointers array to separate (op, arg1, arg2) array Order[0] → &Trip[0]
Order[1] → &Trip[1] 		Combines the space efficiency of triples with the reordering freedom of quadruples. Optimizers move pointers in the Order[] array without touching the triple memory records.

4. Complete Reconstructible C Code (Minimal Clean Form)

#include <stdio.h>
#include <string.h>
#include <stdlib.h>

void assignment_tac(char exp[]);
void arithmetic_tac(char exp[]);
void relational_tac(char exp[]);

int addr = 100;

int main() {
    int ch;
    char exp[50];
    
    while (1) {
        printf("\n1. Assignment\n2. Arithmetic\n3. Relational\n4. Exit\nChoice: ");
        if (scanf("%d", &ch) != 1) break;
        if (ch == 4) break;
        
        printf("Enter expression: ");
        scanf("%s", exp);
        
        switch (ch) {
            case 1: assignment_tac(exp); break;
            case 2: arithmetic_tac(exp); break;
            case 3: relational_tac(exp); break;
            default: printf("Invalid choice!\n");
        }
    }
    return 0;
}

void assignment_tac(char exp[]) {
    int i = 0, l = strlen(exp);
    char lhs[10], rhs[20];
    
    while (exp[i] != '=' && i < l) {
        lhs[i] = exp[i];
        i++;
    }
    lhs[i] = '\0';
    
    if (i >= l) {
        printf("Error: Missing '='\n");
        return;
    }
    
    strcpy(rhs, &exp[i + 1]);
    
    int op_pos = -1;
    for (int j = 0; rhs[j] != '\0'; j++) {
        if (rhs[j] == '+' || rhs[j] == '-' || rhs[j] == '*' || rhs[j] == '/') {
            op_pos = j;
            break;
        }
    }
    
    printf("\nThree Address Code:\n");
    if (op_pos != -1) {
        char op1[10], op2[10];
        strncpy(op1, rhs, op_pos);
        op1[op_pos] = '\0';
        strcpy(op2, &rhs[op_pos + 1]);
        printf("temp = %s %c %s\n", op1, rhs[op_pos], op2);
        printf("%s = temp\n", lhs);
    } else {
        printf("temp = %s\n", rhs);
        printf("%s = temp\n", lhs);
    }
}

void arithmetic_tac(char exp[]) {
    int l = strlen(exp);
    int op_idx = -1;
    
    for (int i = 0; i < l; i++) {
        if (exp[i] == '*' || exp[i] == '/') {
            op_idx = i;
            break;
        }
    }
    
    printf("\nThree Address Code:\n");
    if (op_idx != -1) {
        /* High precedence operator found */
        printf("temp = %c %c %c\n", exp[op_idx - 1], exp[op_idx], exp[op_idx + 1]);
        if (op_idx + 2 < l) {
            printf("temp1 = temp %c %c\n", exp[op_idx + 2], exp[op_idx + 3]);
        } else if (op_idx - 2 >= 0) {
            printf("temp1 = %c %c temp\n", exp[op_idx - 3], exp[op_idx - 2]);
        }
    } else {
        /* Only addition or subtraction */
        printf("temp = %c %c %c\n", exp[0], exp[1], exp[2]);
        if (l > 3) {
            printf("temp1 = temp %c %c\n", exp[3], exp[4]);
        }
    }
}

void relational_tac(char exp[]) {
    printf("\nThree Address Code:\n");
    printf("%d: if %s goto %d\n", addr, exp, addr + 3);
    printf("%d: T = 0\n", addr + 1);
    printf("%d: goto %d\n", addr + 2, addr + 4);
    printf("%d: T = 1\n", addr + 3);
    addr += 4;
}

5. Examiner Viva Traps & Checkpoints

  • Why does addr increment by 4? The relational code template consumes four contiguous instruction addresses: the conditional jump (addr), the false assignment (addr + 1), the unconditional skip jump (addr + 2), and the true assignment (addr + 3). Advancing by 4 (addr += 4) guarantees that subsequent relational blocks or surrounding control statements receive fresh, non-overlapping label addresses starting at addr + 4.
  • What is the TAC constraint? An instruction may reference at most 3 addresses (up to 2 source operands and 1 destination). This matches standard assembly architectures (e.g., RISC / x86 load-operate-store paradigms), enabling direct instruction selection and register allocation.
  • Why do Quadruples need more memory than Triples? Quadruples dedicate an explicit fourth field to store the result/temporary variable name (e.g., t1). Triples omit this field and refer to results implicitly via the statement array index (e.g., (0)). However, triples make compiler optimizations (like loop code motion and dead code elimination) harder because moving statements requires rewriting index pointers throughout the program.
  • How does arithmetic_tac implement precedence? It implements a two-pass priority scan. Pass 1 searches for high-precedence operators (* and /) and isolates their neighboring operands into temp. Pass 2 binds the remaining lower-precedence addition/subtraction operand with temp into temp1.
