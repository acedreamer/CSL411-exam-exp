LEX & YACC Calculator Cheat Sheet

Architectural invariant, syntax contracts, and terminal commands.

1. The Four-Command Pipeline

yacc -d calc.y                  # Generates y.tab.c (parser) and y.tab.h (token constants)
lex calc.l                      # Generates lex.yy.c (scanner)
gcc lex.yy.c y.tab.c -w -o calc # Links scanner and parser into executable
./calc                          # Runs the interactive evaluator

2. Communication Contract

Component Direction Carrier Purpose
Token Type LEX → YACC return NUMBER; Identifies grammar category to the LALR(1) stack.
Token Value LEX → YACC yylval = atoi(yytext); Hands over numerical magnitude of the lexeme.
Token IDs YACC → LEX #include "y.tab.h" Imports numeric enum constant for NUMBER.
Syntactic Value YACC → Stack $$ = $1 + $3; Computes LHS attribute from RHS children during reduction.

3. The Exact Source Skeletons

A. calc.l (Lexical Analyzer)

%{
#include <stdio.h>
#include "y.tab.h"
extern int yylval;
%}

%%
[0-9]+      { yylval = atoi(yytext); return NUMBER; }
[\n]        { return 0; }
[ \t]       ; /* Ignore whitespace */
.           { return yytext[0]; }
%%

int yywrap() {
    return 1;
}

B. calc.y (Parser & Semantic Evaluator)

%{
#include <stdio.h>
#include <stdlib.h>

int flag = 0;
int yylex();
void yyerror(const char *s);
%}

%token NUMBER
%left '+' '-'
%left '*' '/' '%'
%left '(' ')'

%%
Calculate : E {
    printf("The calculated value is: %d\n", $$);
} ;

E : E '+' E    { $$ = $1 + $3; }
  | E '-' E    { $$ = $1 - $3; }
  | E '*' E    { $$ = $1 * $3; }
  | E '/' E    { 
        if ($3 == 0) {
            printf("\nRuntime Error: Division by zero!\n");
            flag = 1;
            YYABORT;
        } else {
            $$ = $1 / $3;
        }
    }
  | E '%' E    { $$ = $1 % $3; }
  | '(' E ')'  { $$ = $2; }
  | NUMBER     { $$ = $1; }
  ;
%%

int main() {
    printf("Enter expression:\n");
    yyparse();
    if (flag == 0) printf("Evaluation successful.\n");
    return 0;
}

void yyerror(const char *s) {
    flag = 1;
    printf("Invalid expression, unable to parse.\n");
}

4. Precedence Rules & Examiner Traps

  • Declaration Order: Declarations listed lower in the YACC declaration block have higher precedence. Hence, %left '*' '/' '%' binds tighter than %left '+' '-'.
  • Parentheses: Declaring %left '(' ')' at the bottom guarantees that subexpressions inside parentheses take highest binding priority.
  • Why return 0 on \n: A return value of 0 or EOF notifies yyparse() that the input stream is exhausted, triggering final reduction to the start symbol.
  • Why -d is mandatory: Without -d, YACC will not generate y.tab.h, causing calc.l to fail compilation with error: NUMBER undeclared.
