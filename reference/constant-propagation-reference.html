Constant Propagation Cheat Sheet

Quadruple specifications, evaluation guards, and forward propagation mechanics.

1. Quadruple Representation

Each intermediate code statement is stored as an instance of struct expression:

Field Type Example Role in Optimization
op char[2] "+", "=" Operator applied to operands (or assignment).
op1 char[5] "3", "a" First operand (can start as variable and be overwritten with digit).
op2 char[5] "5", "?" Second operand (dummy placeholder "?" for direct assignments).
res char[5] "b" Target identifier where computed value was assigned.
flag int 0 or 1 0 = active (retained in output); 1 = eliminated (folded).

2. Complete Reconstructible C Code (Minimal Form)

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>

struct expression {
    char op[2], op1[5], op2[5], res[5];
    int flag;
} arr[10];
int n;

void change(int i, int res) {
    char buf[5];
    sprintf(buf, "%d", res);
    for (int j = i + 1; j < n; j++) {
        if (strcmp(arr[i].res, arr[j].op1) == 0) strcpy(arr[j].op1, buf);
        if (strcmp(arr[i].res, arr[j].op2) == 0) strcpy(arr[j].op2, buf);
    }
}

void constant() {
    for (int i = 0; i < n; i++) {
        if ((isdigit(arr[i].op1[0]) && isdigit(arr[i].op2[0])) ||
            (strcmp(arr[i].op, "=") == 0 && isdigit(arr[i].op1[0]))) {
            
            int v1 = atoi(arr[i].op1), v2 = atoi(arr[i].op2), ans = 0;
            switch (arr[i].op[0]) {
                case '+': ans = v1 + v2; break;
                case '-': ans = v1 - v2; break;
                case '*': ans = v1 * v2; break;
                case '/': ans = (v2 != 0) ? v1 / v2 : 0; break;
                case '=': ans = v1; break;
            }
            arr[i].flag = 1;
            change(i, ans);
        }
    }
}

int main() {
    printf("Enter number of expressions: ");
    scanf("%d", &n);
    printf("Enter quadruples (op op1 op2 res):\n");
    for (int i = 0; i < n; i++) {
        scanf("%s %s %s %s", arr[i].op, arr[i].op1, arr[i].op2, arr[i].res);
        arr[i].flag = 0;
    }
    constant();
    printf("\nOptimized Code:\n");
    for (int i = 0; i < n; i++) {
        if (arr[i].flag == 0) {
            printf("%s %s %s %s\n", arr[i].op, arr[i].op1, arr[i].op2, arr[i].res);
        }
    }
    return 0;
}

3. Viva Traps & Examiner Checkpoints

  • Folding vs. Propagation: Folding is the compile-time calculation of arithmetic on numeric literals (e.g., $3 + 5 \to 8$). Propagation is the forward substitution of the known constant into subsequent statements referencing that variable.
  • Forward-Only Loop ($j = i + 1$): Propagation must never scan backwards. In straight-line code, instructions prior to row $i$ precede the assignment and cannot see the new value.
  • Dead Code Elimination: Setting flag = 1 suppresses printing of redundant assignments, effectively performing basic-block dead-code elimination.
  • Single-Pass Limitation: If an expression in row $k$ becomes constant because of later evaluations in a non-topological schedule, a single forward pass will not catch it. Full optimizers iterate until reaching a fixed point.
