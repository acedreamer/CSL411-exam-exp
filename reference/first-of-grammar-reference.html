FIRST Set of Grammar Cheat Sheet

Grammar indexing conventions, recursive descent mechanics, deduplication, and minimal C skeleton.

1. Grammar Conventions & Invariants

Each production rule string in p[i] follows the strict rigid format LHS=RHS:

Array Index Component Classification Semantic Role
p[i][0] LHS Non-Terminal isupper(p[i][0]) Grammar variable being expanded (e.g., 'E', 'T', 'F').
p[i][1] Separator Literal '=' Distinguishes head from production body.
p[i][2] Leading RHS Symbol Variable, Terminal, or '$' The first symbol produced; dictates immediate or recursive FIRST inclusion.
p[i][3...] Subsequent RHS Grammar symbols Rest of the production tail (e.g., 'X' in "E=TX").

2. Core Data Structures

Variable Type Scope Purpose
p[20][20] char[20][20] Global Stores up to 20 production strings of length up to 20 bytes (e.g., "E=TX", "X=$").
f[20] char[20] Global Accumulator buffer holding the unique characters belonging to the computed FIRST set.
m int Global Index counter tracking the number of unique elements currently placed into f.
n int Global Total count of productions input by the user.
c char Local Query non-terminal symbol passed by the user into first(c).

3. Complete Reconstructible C Code (Under 35 Lines)

#include <stdio.h>
#include <ctype.h>

char p[20][20], f[20];
int m = 0, n;

void add_to_result(char ch) {
    for (int i = 0; i < m; i++)
        if (f[i] == ch) return;
    f[m++] = ch;
}

void first(char c) {
    if (!isupper(c)) { add_to_result(c); return; }
    for (int i = 0; i < n; i++) {
        if (p[i][0] == c) {
            if (p[i][2] == '$') add_to_result('$');
            else if (!isupper(p[i][2])) add_to_result(p[i][2]);
            else first(p[i][2]);
        }
    }
}

int main() {
    char c;
    printf("Enter number of productions: ");
    scanf("%d", &n);
    printf("Enter productions (LHS=RHS, '$' for epsilon):\n");
    for (int i = 0; i < n; i++) scanf("%s", p[i]);
    printf("Enter non-terminal: ");
    scanf(" %c", &c);
    first(c);
    printf("FIRST(%c) = { ", c);
    for (int i = 0; i < m; i++) printf("%c%s", f[i], i < m - 1 ? ", " : "");
    printf(" }\n");
    return 0;
}

4. Core Mathematical Rules vs. C Code Mapping

Formal Grammar Rule C Conditional Implementation Action Taken
Base Case: If $X$ is a terminal, $\text{FIRST}(X) = \{ X \}$. if (!isupper(c)) add_to_result(c); return;
Epsilon Rule: If $X \to \epsilon$, add $\epsilon$ to $\text{FIRST}(X)$. if (p[i][2] == '$') add_to_result('$');
Terminal Prefix: If $X \to a\alpha$ where $a$ is terminal. else if (!isupper(p[i][2])) add_to_result(p[i][2]);
Non-Terminal Prefix: If $X \to Y\alpha$ where $Y$ is non-terminal. else (i.e. isupper(p[i][2])) Recursive call first(p[i][2]);

5. Viva Traps & Examiner Checkpoints

  • Left Recursion Infinite Descent: If a grammar contains direct left recursion (e.g., $E \to E + T$), calling first('E') inspects p[i][2] which is 'E', triggering first('E') repeatedly until stack overflow occurs. Defense: CFGs must undergo left-recursion elimination before predictive FIRST/FOLLOW calculation.
  • Character Classification via isupper(): The program relies on <ctype.h>: uppercase letters ($A-Z$) are non-terminals, while lowercase letters, symbols (+, *, (, )), digits, and the sentinel $ evaluate to false under isupper() and are treated as terminals.
  • Set Deduplication Invariant: In set theory, $\{ i, (, i \} = \{ i, ( \}$. The function add_to_result(char ch) performs a linear scan over $f[0 \dots m-1]$. If ch exists, it returns immediately without incrementing m.
  • Epsilon Representation: In KTU lab evaluations, epsilon ($\epsilon$) is customarily entered as $, but some lab manuals use # or e. Be ready to change the literal character check in p[i][2] == '$' if requested.
  • The Leading Symbol Assumption: In full LL(1) theory, if $p[i][2]$ can derive epsilon ($\epsilon \in \text{FIRST}(p[i][2])$), the algorithm must check $p[i][3]$ and subsequent symbols. In this standard KTU foundational lab code, the grammar is structured such that leading symbols define the first token.
