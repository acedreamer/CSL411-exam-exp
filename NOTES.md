# Teaching Notes & User Preferences

- **Primary Goal:** Learn by understanding the core computational logic, not through rote memorization.
- **Target Output:** Ability to write down the code for the five programs from memory on a blank sheet or empty IDE.
- **Teaching Tone:** Patient, rigorous, pedagogical, structured with visual models and active recall.
- **Pedagogical Strategy:**
  - Build strong storage strength through mental models, analogies, and active retrieval.
  - Break each program into the Lexical/Syntactic contract, the minimal skeleton, and the edge cases.
  - Test via interactive quizzes with balanced options before advancing.
